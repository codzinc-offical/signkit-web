# SignKit - Landing Page & Web Portal

Official landing page for **SignKit** — the premier document signing, PDF annotation, and e-signature application.

## Live Website
Visit the live site: [https://codzinc-offical.github.io/signkit-web/](https://codzinc-offical.github.io/signkit-web/)

## Features
- **Sign PDF Documents**: Import, annotate, and place digital signatures seamlessly.
- **Custom Digital Signatures**: Draw, style, and save reusable personal signatures.
- **Official Stamps & Seals**: Insert company stamps and verification emblems.
- **Document Management**: Manage, export, and share signed agreements securely.
